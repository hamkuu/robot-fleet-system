# Robot Fleet System

Distributed Robot Fleet System.

## Getting-started

```bash
docker compose build
docker compose up
```

## Simple UI

Open [http://localhost:8000/ui](http://localhost:8000/ui) to browse, upload, download, edit
metadata, and delete published images.

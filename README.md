# Robot Fleet System

Distributed Robot Fleet System.

## Getting-started

```bash
docker compose build
docker compose up
```

## Accessible Services

- [Simple UI on Backend](http://localhost:8000/ui)
- [Backend OpenAPI docs](http://localhost:8000/docs)
- [Database Adminer](http://localhost:8010)
